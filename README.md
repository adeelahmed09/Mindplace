# Mindplace

Mindplace is a responsive clone static website created using HTML, CSS, JavaScript, and the GSAP library. This project showcases modern web development techniques and animations to create an engaging user experience.

## Features

- **Responsive Design**: The website is fully responsive and looks great on all devices.
- **Modern Animations**: Utilizes the GSAP library for smooth animations.
- **Clean and Modular Code**: Written with clean and maintainable code practices.

## Live Demo

Check out the live demo of the project [here](https://adeelahmed09.github.io/Mindplace/).

## Technologies Used

- HTML
- CSS
- JavaScript
- GSAP (GreenSock Animation Platform)

## Installation

To run this project locally, follow these steps:

1. Clone the repository:
    ```bash
    git clone https://github.com/adeelahmed09/Mindplace.git
    ```
2. Navigate to the project directory:
    ```bash
    cd Mindplace
    ```
3. Open `index.html` in your preferred web browser.

## Usage

Feel free to explore the code and modify it as you like. The project is a great starting point for learning responsive web design and advanced animations.
